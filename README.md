# 🔐 Password Security Analyzer

A modern Password Security Analyzer built using Java, Spring Boot, HTML, CSS, and JavaScript.

## Features

* Password Strength Analysis
* Entropy Calculation
* Secure Password Generator
* Weak Password Detection
* Password Security Suggestions
* Interactive Animated UI

## Tech Stack

* Java 21
* Spring Boot
* Maven
* HTML
* CSS
* JavaScript

## API Endpoints

### Analyze Password

POST /api/password/analyze

### Generate Password

GET /api/password/generate

## Run Locally

```bash
mvn spring-boot:run
```

Open:

http://localhost:8080
